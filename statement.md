# Project Statement

## Project Title
LibraSync — Smart Library Management System with Concurrent Book Reservation

## Problem Statement
Traditional library systems can become inefficient when multiple users try to access
or reserve the same book at nearly the same time. LibraSync provides a command-line
library system for managing users, books, borrowing, returning, and reservations,
while demonstrating synchronized concurrent reservation handling.

## Scope
- User registration and authentication
- Book search and management
- Borrowing and returning
- Reservation queue
- Concurrent reservation demonstration
- Basic library reports
- Persistent storage using SQLite through JDBC

## Target Users
- Students/library members
- Librarians/administrators

## High-Level Features
- OOP-based domain model
- Collections for in-memory processing
- Exception handling and validation
- Java threads and synchronization
- JDBC database connectivity
- Command-line execution
